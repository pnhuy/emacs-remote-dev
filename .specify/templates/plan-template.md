## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Check the plan against `.specify/memory/constitution.md`. Record PASS / FAIL (with a Complexity
Tracking entry and documented exception) for each:

- **I Architecture**: existing behavior, `/rdev:HOST:/path`, JSON-RPC over SSH and relay preserved;
  breaking changes have justification, migration path and regression tests
- **II Native Emacs**: integrates via file-name handlers and standard Emacs APIs; TRAMP and
  unrelated workflows untouched; compatibility shown by executable tests
- **III Data integrity**: no silent loss of edits, atomic saves, conflict detection, no blind
  replay of non-idempotent operations
- **IV Security**: least privilege, no root, validated and bounded input, no plaintext TCP by
  default, tokens never logged, automated security tests
- **V Performance**: blocking acknowledged, bounded memory and concurrency, benchmark-backed
- **VI Dependencies**: built-ins and stdlib first, Emacs 30.1+, tested Python versions, optional
  tools stay optional
- **VII Testing**: ERT + Python unit tests, protocol tests, regression tests before refactoring,
  known failures documented
- **VIII Protocol**: JSON-RPC 2.0 and Content-Length framing, frozen methods, negotiated
  capabilities, effect on deployed agents assessed
- **IX Maintainability** / **X UX**: incremental refactoring, documented public API, visible
  connection state, distinguishable errors
- **XI Workflow** / **XII Done**: existing code inspected, confirmed vs suspected defects separated,
  verification limits reported
